# 弾幕ゲーム

## 概要

30秒間、さまざまな弾幕を避け続けるゲーム
制限時間まで生き残るとクリア

## 制作背景

東方Projectのような弾幕ゲームを作ってみたかったから

## こだわり・工夫点

### ゲーム設計

- 自分は弾を打てず、よけるだけとする
- 弾の種類は複数ある
- リスタートできる
- スマホ対応あり

### 制作

- 実装はChatGPTを活用
- 仕様設計と挙動検証は自身で
- ロジックを理解した上で整理・修正

## 遊び方

- 制限時間を生きのびればクリア
- プレイヤーが弾に触れると一発アウト

### 操作方法

#### PC

- 移動：矢印キーまたはWASD
- 低速移動：Shift

#### スマホ

- 移動：画面をタッチ
- タッチした位置の少し上に向かってプレイヤーが移動します

### 弾幕の種類

- 0s　円形に広がる弾
- 5s　画面下を直線に進む弾
- 10s 壁で反射する弾
- 15s プレイヤーを狙う弾
- 20s 星形の弾
- 25s 渦巻き状の弾
